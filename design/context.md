# 体验说明 / PRD

## 用户任务
进入展厅即见异兽，旋转观察其结构；切换异兽，阅读设定，收藏感兴趣的条目。

## 视觉方向
Experience 模式。上古博物馆：深石青背景，象牙文字，低饱和古铜细线，朱砂印记。模型是焦点，文本和工具退居两侧。首屏无广告式大标题或营销卡片。真实几何和灯光承担景深与材质。

## 页面
1. 观兽：三维展示、名称、简介、种属、档案入口、相邻切换、缩略图导航。
2. 图鉴：全部20只，名称/别名/形态搜索，分类筛选。
3. 收藏：本机保存的条目，空态引导返回图鉴。
4. 档案：外观、行为、声音、创作栖境与来源说明。

## 状态
模型加载进度、失败重试、WebGL不可用静态预览、音频开启失败、收藏存储失败、无搜索结果、无收藏。

## 资产与动作
高精主资产按需加载，一次只保留当前模型。优先使用导入动画；无骨骼动画时仅提供明确的镜头巡览和展示呼吸，不能将整体变换称为完整骨骼动作。

## 风险
生成模型的复杂头/尾/翼数量需目视复核。高精模型下载与GPU成本高；以像素比上限和按需加载控制。环境有Tripo凭据，Blender交互连接初始不可用。
